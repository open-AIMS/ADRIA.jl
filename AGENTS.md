# Reproducible core-model development rules

These instructions apply to the ADRIA repository, including `sandbox/calibration`.
The ecological COTS transition code is maintained in the sibling `COTSMod.jl`
repository; changes that cross that boundary must satisfy the rules below in both
repositories.

## Preserve a reproducible baseline

- New ecological mechanisms must be opt-in until they pass the promotion gates.
  Default settings must reproduce the previously supported model path.
- Never change a calibrated parameter meaning, state unit, matrix orientation, or
  time convention silently. Document the migration and add a compatibility test.
- COTS abundance states, thresholds, fluxes, and observation mappings must declare
  their units. The calibration contract treats model COTS state as `COTS ha^-1`;
  CPUE conversion belongs in the observation model, not the ecological transition.
- Every stochastic mechanism must accept a recorded seed. Do not draw from an
  unrecorded global RNG in calibration or validation workflows.
- Derived data must be generated by a checked-in script. Record source paths,
  hashes, transformations, dimensions, units, orientation, and output hashes.

## Structure each mechanism change

Before changing the core model, write down:

1. the ecological hypothesis;
2. the mathematical/state-transition change;
3. expected observable consequences, including peak timing and amplitude;
4. the control treatment and the smallest discriminating factorial;
5. parameter units, evidence, and defensible bounds;
6. failure criteria and rollback path.

Implement the mechanism behind an explicit configuration switch. Add pure unit
tests in `COTSMod.jl`, adapter/integration tests in ADRIA, and a bounded calibration
experiment. Log component fluxes so that a change cannot improve the objective for
an unidentified reason.

## Promotion gates

A mechanism may be promoted from experimental to the default model only when all
of the following are true:

1. The legacy control, unit tests, parse tests, and data-provenance checks pass.
2. The mechanism produces the missing qualitative behavior before large-scale
   optimization. For the current COTS work this means a plausible second outbreak
   peak, not merely a lower aggregate loss.
3. Peak timing, height, prominence, and inter-peak period improve under replicated
   seeds without unacceptable degradation of coral dynamics or mass balance.
4. The result survives a frozen objective, held-out reefs or years, and an
   independently configured regional validation where suitable observations exist.
5. Sensitivity analysis shows that the result is not confined to an implausibly
   narrow parameter region.
6. Run metadata contains ADRIA and COTSMod revisions, environment/configuration,
   seeds, package versions, input hashes, failures, and per-reef scores.
7. The calibration README and protocol record the decision, evidence, limitations,
   and exact reproduction command.

Do not compensate for a missing mechanism by widening or lowering an independently
supported biological threshold. In particular, hold the COTS Allee threshold at
the evidence-based value during the connectivity/juvenile-storage experiments;
threshold variation is a labelled counterfactual only.

## Connectivity and boundary conditions

- Keep source-to-sink orientation explicit and test mass preservation when moving
  between reef and site scales.
- Do not average annual connectivity unless the treatment is explicitly the static
  control. Preserve the selected hydrodynamic year in outputs.
- Apply reef-specific larval-survival modifiers at the source and record their
  source dataset/scenario.
- Separate local production, local retention, internal immigration, and external
  boundary supply in diagnostics. External supply must use absolute, documented
  recruitment-flux units and must not be mislabeled as adult density or scaled
  to the model's previous internal maximum.
- Spatial subsets must state whether they are open or closed. A closed Lizard
  subset must not be interpreted as evidence that the full GBR network cannot
  reseed it.

## Calibration discipline

- Freeze the scoring function and observation model before comparing mechanisms.
- Use the smallest bounded factorial that can distinguish competing explanations.
- Do not start production optimization, Sobol/PAWN analysis, or multi-seed
  convergence runs until at least one treatment passes the qualitative mechanism
  gate.
- Keep exploratory, calibration, temporal-holdout, and regional-validation outputs
  in distinct run directories. Never overwrite a prior run.
- Failed evaluations are data: log them with the error and candidate identifier.

## Required review checklist

For any pull request or handoff that changes COTS dynamics, report:

- files and equations changed;
- old and new defaults;
- units and boundary assumptions;
- tests and reproduction commands run;
- control-versus-treatment peak metrics;
- known limitations and the next promotion gate.
